## API Reference

Complete reference for all public APIs in `@igniter-js/telemetry`. Every method and type is verified against the implementation in `packages/telemetry/src/`.

---

## IgniterTelemetry (Builder)

**Import:** `import { IgniterTelemetry } from "@igniter-js/telemetry"`

Alias for `IgniterTelemetryBuilder`. Creates and configures telemetry instances.

### Static Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `IgniterTelemetry.create()` | `IgniterTelemetryBuilder` | Create a new builder instance |

### Builder Methods

Builder configuration methods return new builder instances. `buildConfig()` applies the default service name to the current builder when none was set.

| Method | Signature | Description |
|--------|-----------|-------------|
| `.withService(name)` | `(service: string) => Builder` | Set service name (default: `"igniter-app"`) |
| `.withEnvironment(env)` | `(environment: string) => Builder` | Set environment (default: `"development"`) |
| `.withVersion(v)` | `(version: string) => Builder` | Set service version |
| `.addActor(key, opts?)` | `(key: string, opts?: ActorOptions) => Builder` | Register actor type |
| `.addScope(key, opts?)` | `(key: string, opts?: ScopeOptions) => Builder` | Register scope type |
| `.addEvents(desc, opts?)` | `(desc: EventsDescriptor, opts?: ValidationOptions) => Builder` | Register typed events |
| `.addTransport(adapter)` | `(adapter: TransportAdapter) => Builder` | Add transport adapter |
| `.withSampling(policy)` | `(policy: SamplingPolicy) => Builder` | Configure sampling |
| `.withRedaction(policy)` | `(policy: RedactionPolicy) => Builder` | Configure redaction |
| `.withValidation(opts)` | `(opts: ValidationOptions) => Builder` | Set global validation options |
| `.withLogger(logger)` | `(logger: IgniterLogger) => Builder` | Set internal logger |
| `.build()` | `IgniterTelemetryManager` | Create runtime manager |
| `.buildConfig()` | `IgniterTelemetryConfig` | Build config only |

### ActorOptions


### ScopeOptions

## IgniterTelemetryManager (Runtime)

Returned by `.build()`. The runtime instance for emitting events.

### Properties

| Property | Type | Description |
|----------|------|-------------|
| `service` | `string` | Service name |
| `environment` | `string` | Environment name |
| `version` | `string \| undefined` | Service version |

### Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| `.emit(name, input?)` | `(name: string, input?: EmitInput) => void` | Emit an event; arbitrary string names are accepted |
| `.session()` | `() => IgniterTelemetrySession` | Create a new session |
| `.flush()` | `() => Promise<void>` | Invoke each adapter's optional flush hook; errors are caught and logged when a logger is configured |
| `.shutdown()` | `() => Promise<void>` | Invoke flush and adapter shutdown hooks; does not wait for in-flight `emit()` deliveries |

### EmitInput

```typescript
interface IgniterTelemetryEmitInput {
  level?: "debug" | "info" | "warn" | "error";
  time?: string;
  sessionId?: string;
  actor?: { type: string; id?: string; tags?: Record<string, string | number | boolean> };
  scope?: { type: string; id: string; tags?: Record<string, string | number | boolean> };
  attributes?: IgniterTelemetryAttributes;
  error?: {
    name: string;
    message: string;
    code?: string;
    stack?: string;
    cause?: string;
  };
  source?: {
    causer?: string;
    file?: string;
    line?: number;
  };
}
```

## IgniterTelemetrySession

Created via `telemetry.session()`. Provides context binding and scoped execution.

### Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| `.actor(type, id?, tags?)` | `(type: string, id?: string, tags?: Tags) => this` | Set actor |
| `.scope(type, id, tags?)` | `(type: string, id: string, tags?: Tags) => this` | Set scope |
| `.attributes(attrs)` | `(attrs: IgniterTelemetryAttributes) => this` | Merge primitive-valued attributes |
| `.id(sessionId)` | `(sessionId: string) => this` | Set custom session ID |
| `.emit(name, input?)` | `(name: string, input?: EmitInput) => void` | Emit with session context |
| `.run(fn)` | `(fn: () => Promise<T> \| T) => Promise<T>` | Scoped execution |
| `.end()` | `() => Promise<void>` | End session |
| `.getState()` | `() => SessionState` | Get session state copy |

### Static Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `IgniterTelemetrySession.getActive()` | `SessionState \| undefined` | Get active session from AsyncLocalStorage |

## IgniterTelemetryEvents

**Import:** `import { IgniterTelemetryEvents } from "@igniter-js/telemetry"`

Creates typed event registries that retain schema descriptors for TypeScript inference. The current runtime does not validate emitted attributes against these schemas.

### Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| `.namespace(name)` | `(name: string) => EventRegistryBuilder` | Start a namespace |
| `.event(name, schema)` | `(name: string, schema: Schema) => EventRegistryBuilder` | Add flat event |
| `.group(name, builder)` | `(name: string, builder: (g: GroupBuilder) => GroupBuilder) => EventRegistryBuilder` | Add nested group |
| `.build()` | `EventsDescriptor` | Build the descriptor |

### EventsDescriptor Helpers

| Helper | Type | Description |
|--------|------|-------------|
| `.get.key(name)` | `(key: string) => string` | Get full event key with namespace |
| `.get.schema(name)` | `(key: string) => Schema` | Get schema for event |
| `.$Infer.namespace` | `string` | Namespace type |
| `.$Infer.events` | `EventsMap` | Events map type |
| `.$Infer.keys` | `string union` | All event key types |
| `.$Infer.registry` | `Registry` | Full registry type |

## Error Codes

```typescript
import { IgniterTelemetryError, IGNITER_TELEMETRY_ERROR_CODES } from "@igniter-js/telemetry";

// Configuration
TELEMETRY_SERVICE_REQUIRED
TELEMETRY_ENVIRONMENT_REQUIRED
TELEMETRY_CONFIGURATION_INVALID

// Transport
TELEMETRY_INVALID_TRANSPORT
TELEMETRY_TRANSPORT_FAILED
TELEMETRY_TRANSPORT_INIT_FAILED

// Events
TELEMETRY_INVALID_EVENT_NAME

// Schema & Validation
TELEMETRY_SCHEMA_VALIDATION_FAILED
TELEMETRY_INVALID_NAMESPACE
TELEMETRY_RESERVED_NAMESPACE
TELEMETRY_DUPLICATE_NAMESPACE

// Sessions
TELEMETRY_SESSION_ENDED

// Scope & Actor
TELEMETRY_DUPLICATE_SCOPE
TELEMETRY_DUPLICATE_ACTOR

```

The exported error-code object also includes identifiers the current runtime does not raise on normal public flows: `TELEMETRY_SERVICE_REQUIRED`, `TELEMETRY_ENVIRONMENT_REQUIRED`, `TELEMETRY_CONFIGURATION_INVALID`, `TELEMETRY_UNKNOWN_EVENT`, `TELEMETRY_DUPLICATE_EVENT`, `TELEMETRY_SCHEMA_VALIDATION_FAILED`, `TELEMETRY_SESSION_INVALID`, `TELEMETRY_INVALID_SCOPE`, `TELEMETRY_INVALID_ACTOR`, `TELEMETRY_EMIT_FAILED`, and `TELEMETRY_RUNTIME_NOT_INITIALIZED`. `emit()` accepts arbitrary string names, and duplicate event keys in a registry overwrite earlier entries. See [Troubleshooting](/docs/telemetry/troubleshooting) for source-reachable cases.

### Error Class

## Utility Exports

These classes and constants are runtime exports from the package root and their source barrels (`utils` or `types`). The package manifest exposes the root and adapter subpaths; it does not define a `./utils` or `./types` package subpath, so import these names from `@igniter-js/telemetry`.

| Runtime export | Public methods | Purpose |
|---------------|----------------|---------|
| `IgniterTelemetryId` | `generateSessionId()`, `generateSpanId()`, `generateTraceId()`, `isValidSessionId(id)` | Create IDs and check session ID format |
| `IgniterTelemetryKeyValidator` | `validateKey(key, context)` | Reject empty keys, spaces, and reserved prefixes |
| `IgniterTelemetryValidator` | `validate(name, context)`, `validateEventName(name, context)`, `validateNamespace(namespace)` | Validate event/group and namespace names |
| `IgniterTelemetryRedaction` | `createRedactor(policy?)`, `createSyncRedactor(policy?)`, `redactEnvelope(envelope, policy?)` | Redact attributes or an envelope |
| `IgniterTelemetrySampling` | `matchesPattern(pattern, eventName)`, `shouldSample(policy, eventName, level)`, `createSampler(policy?)` | Match event patterns and produce sampling decisions |
| `IGNITER_TELEMETRY_DEFAULT_REDACTION_POLICY` | — | Default denylist/hash lists and maximum string length |
| `IGNITER_TELEMETRY_DEFAULT_SAMPLING_POLICY` | — | Default per-level rates and pattern lists |
| `IGNITER_TELEMETRY_LEVELS`, `IGNITER_TELEMETRY_LEVEL_PRIORITY`, `isIgniterTelemetryLevel(value)` | — | Runtime level list, priorities, and type guard |

The policy constants have type `Required<IgniterTelemetryRedactionPolicy>` and `Required<IgniterTelemetrySamplingPolicy>`. Import the corresponding policy interfaces with `import type`.

## Supporting Type Exports

The package root re-exports these declarations from `src/types`. They are TypeScript-only exports and should be imported with `import type`; they do not create runtime values.

| Area | Exported types |
|------|----------------|
| Builder and configuration | `IgniterTelemetryBuilderState`, `IgniterTelemetryActorOptions`, `IgniterTelemetryScopeOptions`, `IgniterTelemetryConfig` |
| Manager and input | `IIgniterTelemetryManager`, `IgniterTelemetryEmitInput`, `IgniterTelemetryActorInput`, `IgniterTelemetryScopeInput` |
| Envelope | `IgniterTelemetryTags`, `IgniterTelemetryAttributes`, `IgniterTelemetryActor`, `IgniterTelemetryScope`, `IgniterTelemetryErrorInfo`, `IgniterTelemetrySource`, `IgniterTelemetryEnvelope` |
| Event schemas and registry | `IgniterTelemetryBaseSchema`, `IgniterTelemetryEventSchema`, `IgniterTelemetryEventDescriptor`, `IgniterTelemetryEventsMap`, `IgniterTelemetryEventsRegistry`, `IgniterTelemetryFlattenEventKeys`, `IgniterTelemetryFlattenRegistryKeys`, `IgniterTelemetryGetEventSchema`, `IgniterTelemetryInferEventSchema`, `IgniterTelemetryEventsValidationOptions`, `IgniterTelemetryEventsDescriptor` |
| Levels and policies | `IgniterTelemetryLevel`, `IgniterTelemetryRedactionPolicy`, `IgniterTelemetrySamplingPolicy` |
| Session | `IgniterTelemetrySessionState`, `IgniterSessionEmitCallback`, `IIgniterTelemetrySession` |
| Transport | `IgniterTelemetryTransportType`, `IgniterTelemetryTransportMeta`, `IgniterTelemetryTransportAdapter`, `IgniterTelemetryTransportConfig` |
| Errors | `IgniterTelemetryErrorCode`, `IgniterTelemetryErrorPayload` |

`IgniterTelemetryError`, the error-code object, utility classes, level constants, and level guard are runtime exports. Adapter classes and adapter option types are also exported from `@igniter-js/telemetry/adapters`.

### Adapter Configuration Types

Import these type-only interfaces from `@igniter-js/telemetry/adapters`:

| Adapter | Configuration type |
|---------|--------------------|
| Logger | `LoggerTransportConfig` |
| HTTP | `HttpTransportConfig` |
| OTLP Logs | `OtlpTransportConfig` |
| Sentry | `SentryTransportConfig` |
| Slack | `SlackTransportConfig` |
| Discord | `DiscordTransportConfig` |
| Telegram | `TelegramTransportConfig` |
| Store stream | `StoreStreamTransportConfig` |

Memory and Mock adapters have no configuration interface. `FileTransportConfig` belongs to an adapter module that is not re-exported by the public adapters barrel.
