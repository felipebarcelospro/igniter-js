## Tool groups

All tool groups are enabled by default. Set the matching environment variable to the exact string `false` to disable a group. Input names below match the Zod schemas registered in `packages/mcp-server/src/toolsets/`; optional fields are marked `?`.

| Tool group | Tools and declared inputs |
| --- | --- |
| **CLI** | `start_dev_server(port?, watch?)`; `build_project(mode?)`; `run_tests(filter?, watch?)`; `generate_feature(name, schema?)`; `generate_schema` (currently registers no input schema); `add_package_dependency(package_name, version?, dev_dependency?)`; `remove_package_dependency(package_name)`. |
| **API validation** | `get_openapi_spec(url?)`; `make_api_request(method, url, headers?, body?, timeout?)`. |
| **Documentation** | `read_as_markdown(url)`. |
| **GitHub** | `search_github_issues(query, repository?, state?, labels?, sort?, order?, per_page?)`; `create_github_issue(title, body, repository?, labels?, assignees?)`; `get_github_issue(issueNumber, repository?)`; `search_github_code(query, repository?, language?, filename?)`; `read_github_file(owner, repo, path, ref?)`; `list_github_repository_content(owner, repo, path?, ref?)`; `update_github_issue(issueNumber, repository?, title?, body?, labels?, assignees?, state?, milestone?)`; `close_github_issue(issueNumber, repository?)`; `list_github_issue_comments(issueNumber, repository?, per_page?, page?)`; `create_github_issue_comment(issueNumber, body, repository?)`; `update_github_issue_comment(commentId, body, repository?)`; `delete_github_issue_comment(commentId, repository?)`. |

## Disable groups you do not need

The environment flags are `ENABLE_CLI_TOOLS`, `ENABLE_API_VALIDATION_TOOLS`, `ENABLE_DOCUMENTATION_TOOLS`, `ENABLE_GITHUB_TOOLS`, `ENABLE_FILE_ANALYSIS_TOOLS`, `ENABLE_CODE_INVESTIGATION_TOOLS`, `ENABLE_DEBUGGING_TOOLS`, `ENABLE_MEMORY_TOOLS`, `ENABLE_TASK_MANAGEMENT_TOOLS`, and `ENABLE_AGENT_DELEGATION_TOOLS`.

For example, to disable GitHub and agent delegation in a client configuration:

```json
{
  "env": {
    "ENABLE_GITHUB_TOOLS": "false",
    "ENABLE_AGENT_DELEGATION_TOOLS": "false"
  }
}
```

## Current schema limitations

`generate_schema` currently has no declared input schema even though its handler reads options such as `output`, `watch`, `docs`, and `docsOutput`; clients therefore cannot discover those fields from the registered tool schema. `store_memory` marks `type` optional in its schema, but provide it because the memory manager needs a type to choose the storage location.

`analyze_feature` declares `includeStats` with a default, but its handler does not consume that value. Supplying `includeStats: false` currently does not disable the statistics in the result.

<Callout type="warn">
  `delegate_to_agent` runs delegated work in YOLO mode. `execution_config.network_access`, `fresh_environment`, and `proxy` appear in its input schema but are not forwarded to the runtime configuration in the current implementation. Do not treat those inputs as enforced isolation controls.
</Callout>

The API and documentation toolsets accept arbitrary caller-supplied URLs. `make_api_request` supports mutating HTTP methods, and `inspect_runtime_variable` evaluates an expression in the target process. Connect these tools only to clients and destinations you trust; see [Configuration](/docs/mcp-server-cli/configuration#limit-access).
