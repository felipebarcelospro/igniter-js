The **Jobs** system in Igniter.js provides a powerful, type-safe way to handle background job processing. Built on top of BullMQ and Redis, it allows you to offload time-consuming tasks, schedule jobs for later execution, and process them reliably with built-in retry logic and monitoring.

## Key Features

- **Type-Safe Job Definitions**: Define jobs with Zod schemas for compile-time and runtime type safety
- **Background Processing**: Execute long-running tasks without blocking your API
- **Flexible Scheduling**: Schedule jobs for later execution or set up recurring cron jobs
- **Comprehensive Retry Logic**: Built-in retry strategies with exponential backoff, linear, and custom delays
- **Job Lifecycle Hooks**: React to job events with `onStart`, `onSuccess`, `onFailure`, and `onComplete` hooks
- **Multi-Tenancy Support**: Organize jobs by namespace and use queue prefixes for multi-tenant applications
- **Advanced Monitoring**: Search, filter, and monitor job status, execution times, and results

## Architecture Overview

Igniter.js Jobs follow an **adapter-based architecture**. The core framework defines the interface (`IgniterJobQueueAdapter`), and concrete implementations (like the BullMQ adapter) provide the actual queue processing.

```typescript
┌─────────────────────────────────────────┐
│         @igniter-js/core               │
│   (Job Queue Interface & Types)         │
└─────────────────┬───────────────────────┘
                  │
                  │ implements
                  │
┌─────────────────▼───────────────────────┐
│    @igniter-js/adapter-bullmq           │
│   (BullMQ Implementation)                │
└─────────────────┬───────────────────────┘
                  │
                  │ uses
                  │
         ┌────────▼────────┐
         │      Redis      │
         │   (Job Queue)   │
         └─────────────────┘
```

## Quick Example

Here's a minimal example showing how to set up and use jobs:

```typescript
import { IgniterJobs, IgniterQueue } from '@igniter-js/jobs';
import { IgniterJobsBullMQAdapter } from '@igniter-js/jobs/adapters';
import { Redis } from 'ioredis';
import { z } from 'zod';

const redis = new Redis(process.env.REDIS_URL);

// 1. Define a queue
const emailQueue = IgniterQueue.create('email')
  .addJob('sendWelcome', {
    input: z.object({ email: z.string().email() }),
    handler: async ({ input, context }) => {
      await context.emailService.sendWelcome(input.email);
      return { sent: true };
    },
  })
  .build();

// 2. Create the jobs instance
export const jobs = IgniterJobs.create()
  .withAdapter(IgniterJobsBullMQAdapter.create({ redis }))
  .withService('my-api')
  .withEnvironment('production')
  .withContext(async () => ({
    emailService: new EmailService(),
  }))
  .addQueue(emailQueue)
  .build();

// 3. Use in your application
await jobs.email.sendWelcome.dispatch({
  input: { email: 'user@example.com' },
});
```
