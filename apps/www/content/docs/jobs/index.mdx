The **Jobs** package in Igniter.js brings type-safe background job processing to your application. Built on a fluent builder API with full TypeScript inference, it supports immediate dispatch, delayed scheduling, cron-based recurrence, multi-queue workers, scoped multi-tenancy, typed job streams, and built-in observability.

## Key Features

- **Type-Safe Builders** — Fluent API with full type inference for queues, jobs, input schemas, and results
- **Adapter-Agnostic** — BullMQ, Bun SQLite, and in-memory adapters — same API, any backend
- **Cron & Delayed Scheduling** — Dispatch immediately, with a delay, at a specific time, or on a cron schedule
- **Worker Management** — Create workers with per-queue concurrency control, rate limiters, and lifecycle hooks
- **Job Lifecycle Hooks** — `onStart`, `onSuccess`, `onFailure`, and `onProgress` hooks on every job
- **Typed Job Streams** — Emit, subscribe, and read typed per-job event streams (great for LLM-chunking, progress, logs)
- **Scope-Based Multi-Tenancy** — Isolate jobs by organization, workspace, or environment with `jobs.scope()`
- **Queue Management** — Pause, resume, drain, clean, obliterate, and inspect queues programmatically
- **Observability** — Built-in events, subscribe API, and optional telemetry integration

## Architecture Overview

Igniter.js Jobs follow an **adapter-based architecture**. The core runtime defines the fluent builder interface and runtime types. Concrete adapters provide the actual queue processing backend.

```

│           @igniter-js/jobs                   │
```

## Quick Example

Here's a minimal example showing how to set up and use jobs:

```typescript
import { IgniterJobs, IgniterQueue } from '@igniter-js/jobs'
import { IgniterJobsMemoryAdapter } from '@igniter-js/jobs/adapters/mock'
import { z } from 'zod'

// 1. Define a queue with jobs
const emailQueue = IgniterQueue.create('email')
  .addJob('sendWelcome', {
    input: z.object({ email: z.string().email(), name: z.string() }),
    handler: async ({ input }) => {
      console.log(`Sending welcome email to ${input.email}`)
      return { sent: true }
    },
  })
  .addCron('dailyDigest', {
    cron: '0 9 * * *',
    handler: async ({ context }) => {
      await context.emailService.sendDailyDigest()
    },
  })
  .build()

// 2. Create the jobs runtime
const jobs = IgniterJobs.create()
  .withAdapter(IgniterJobsMemoryAdapter.create())
  .withService('my-api')
  .withEnvironment('production')
  .withContext(async () => ({
    emailService: new EmailService(),
  }))
  .addQueue(emailQueue)
  .build()

// 3. Dispatch a job
await jobs.email.sendWelcome.dispatch({
  input: { email: 'user@example.com', name: 'Alice' },
})

// 4. Start a worker to process jobs
await jobs.worker.create()
  .addQueue('email')
  .withConcurrency(5)
  .start()
```
