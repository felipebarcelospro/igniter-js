The search and monitoring APIs let you inspect jobs in your queues, track their status, manage queues programmatically, and build observability into your job processing system.

## Searching Jobs

Use `jobs.search()` to find jobs, queues, or workers:

```typescript
// Search for jobs
const failedJobs = await jobs.search('jobs', {
  status: 'failed',
  queue: 'email',
})

// Search for queues
const allQueues = await jobs.search('queues', {})

// Search for workers
const activeWorkers = await jobs.search('workers', {})
```

The `search()` method accepts a target (`'jobs'`, `'queues'`, or `'workers'`) and a filter object. The exact filter shape depends on the adapter implementation.

## Job Inspection

Get detailed information about a specific job:

```typescript
// Get a job instance by ID
const jobInstance = jobs.email.sendWelcome.get('job_abc123')

// Retrieve full job details
const job = await jobInstance.retrieve()
console.log(job.id)            // 'job_abc123'
console.log(job.name)          // 'sendWelcome'
console.log(job.queue)         // 'email'
console.log(job.status)        // 'completed' | 'failed' | 'active' | 'waiting' | 'delayed' | 'paused'
console.log(job.input)         // The original input payload
console.log(job.result)        // The handler return value (if completed)
console.log(job.error)         // Error message (if failed)
console.log(job.progress)      // Progress percentage (0–100)
console.log(job.attemptsMade)  // Number of execution attempts
console.log(job.priority)      // Job priority
console.log(job.createdAt)     // Creation timestamp
console.log(job.startedAt)     // When processing started
console.log(job.completedAt)   // When the job finished
console.log(job.metadata)      // Custom metadata
console.log(job.scope)         // Scope info (if dispatched from scoped instance)
```

### Job Statuses

| Status | Description |
|--------|-------------|
| `waiting` | Job is queued and waiting to be processed |
| `active` | Job is currently being processed |
| `completed` | Job finished successfully |
| `failed` | Job failed (may be retried) |
| `delayed` | Job is waiting for its scheduled time |
| `paused` | Job is in a paused queue |

## Managing Individual Jobs

Get a job instance and control it:

```typescript
const job = jobs.email.sendWelcome.get('job_abc123')

// Check job state
const status = await job.state()        // 'waiting' | 'active' | 'completed' | 'failed' | 'delayed' | 'paused'
const progress = await job.progress()   // 0–100
const logs = await job.logs()           // Array of { timestamp, message, level } entries

// Control the job
await job.retry()                       // Retry the job (if failed)
await job.remove()                      // Remove the job permanently
await job.promote()                     // Promote a delayed job to immediate execution

// Move to failed state with a reason
await job.move('failed', 'Manual intervention required')
```

### Reading Job Logs

```typescript
const logs = await jobs.email.sendWelcome.get('job_abc123').logs()
logs.forEach((log) => {
  console.log(`[${log.timestamp.toISOString()}] [${log.level}] ${log.message}`)
})
```

## Bulk Operations

Use `.many()` for operations on multiple jobs:

```typescript
// Retry multiple failed jobs
await jobs.email.sendWelcome.many(['job_1', 'job_2', 'job_3']).retry()

// Remove multiple jobs
await jobs.email.sendWelcome.many(['job_4', 'job_5']).remove()
```

## Queue Management

Manage queues programmatically through the queue accessor:

```typescript
// Get queue details
const queueInfo = await jobs.email.get().retrieve()
console.log(queueInfo.name)       // 'email'
console.log(queueInfo.isPaused)   // false
console.log(queueInfo.jobCounts)  // { waiting: 5, active: 2, completed: 100, failed: 3, delayed: 1, paused: 0 }

// Control the queue
await jobs.email.get().pause()    // Stop processing new jobs from this queue
await jobs.email.get().resume()   // Resume processing

// Drain all jobs
const drained = await jobs.email.get().drain()
console.log(`Drained ${drained} jobs`)

// Clean completed/failed jobs
const cleaned = await jobs.email.get().clean({
  status: ['completed', 'failed'],
  olderThan: 7 * 24 * 60 * 60 * 1000, // Older than 7 days
  limit: 1000,
})
console.log(`Cleaned ${cleaned} jobs`)

// Obliterate a queue entirely (destructive!)
await jobs.email.get().obliterate({ force: true })

// Retry all failed jobs in a queue
const retried = await jobs.email.get().retryAll()
console.log(`Retried ${retried} jobs`)
```

### Clean Options

| Option | Type | Description |
|--------|------|-------------|
| `status` | `JobStatus \| JobStatus[]` | Statuses to clean |
| `olderThan` | `number` | Only clean jobs older than this (ms) |
| `limit` | `number` | Maximum jobs to clean |

## Listing Queue Jobs

List jobs in a queue with optional filters:

```typescript
// List all jobs in the email queue
const allJobs = await jobs.email.list()

// List with status filter
const failedJobs = await jobs.email.list({
  status: ['failed'],
  limit: 50,
  offset: 0,
})

// Paginate through results
const page1 = await jobs.email.list({ limit: 50, offset: 0 })
const page2 = await jobs.email.list({ limit: 50, offset: 50 })
```

## Worker Inspection

Search for workers and inspect their state:


## Monitoring Patterns

### Queue Health Dashboard

```typescript
async function getQueueHealth() {
  const queues = await jobs.search('queues', {})

  for (const queue of queues) {
    const info = await jobs[queue.name].get().retrieve()
    console.log(`Queue: ${queue.name}`)
    console.log(`  Paused: ${info.isPaused}`)
    console.log(`  Waiting: ${info.jobCounts.waiting}`)
    console.log(`  Active:  ${info.jobCounts.active}`)
    console.log(`  Failed:  ${info.jobCounts.failed}`)
    console.log(`  Delayed: ${info.jobCounts.delayed}`)
  }
}
```

### Alert on Failed Jobs

```typescript
async function monitorFailures() {
  const failedJobs = await jobs.search('jobs', {
    status: 'failed',
  })

  if (failedJobs.length > 50) {
    await alerts.send({
      level: 'critical',
      message: `${failedJobs.length} failed jobs detected`,
    })
  }
}
```

### Find Stale Jobs

```typescript
async function findStaleJobs() {
  const staleThreshold = Date.now() - 60 * 60 * 1000 // 1 hour ago

  const activeJobs = await jobs.search('jobs', {
    status: 'active',
  })

  const stale = activeJobs.filter(
    (job) => job.startedAt && job.startedAt.getTime() < staleThreshold
  )

  for (const job of stale) {
    console.log(`Stale job: ${job.name} (${job.id}) — started ${job.startedAt}`)
  }

  return stale
}
```

## Best Practices

- **Use status filters** — narrow searches to avoid loading all jobs at once
- **Paginate results** — use `limit` and `offset` for large queues
- **Clean regularly** — clean completed/failed jobs to keep queues manageable
- **Monitor failure rates** — set up alerts for abnormal failure spikes
- **Track stale jobs** — detect jobs that are active for too long
- **Use metadata for filtering** — attach meaningful metadata to jobs for search
