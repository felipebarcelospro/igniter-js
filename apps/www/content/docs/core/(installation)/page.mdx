## Quick Start

If you're not sure which framework to choose, or want to quickly test Igniter.js features:

<Steps>
  <Step>
    ### Use the CLI
    
    Start a new project with our interactive CLI:
    
    <Tabs items={['npm', 'pnpm', 'yarn', 'bun']} groupId="package-manager">
      <Tab value="npm">
        ```bash
        npx @igniter-js/cli@latest init
        ```
      </Tab>
      <Tab value="pnpm">
        ```bash
        pnpm dlx @igniter-js/cli@latest init
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn dlx @igniter-js/cli@latest init
        ```
      </Tab>
      <Tab value="bun">
        ```bash
        bunx @igniter-js/cli@latest init
        ```
      </Tab>
    </Tabs>
  </Step>
  
  <Step>
    ### Choose your template
    
    The CLI prompts you to choose a registered starter and then select optional add-ons. The available add-ons are shown by the CLI itself; choices can include database, Redis-backed Store, Jobs, MCP Server, logging, telemetry, bots, auth, and shadcn/ui.
  </Step>
  
  <Step>
    ### Start developing
    
    ```bash
    cd my-igniter-app
    npm run dev
    ```
  </Step>
</Steps>

## Requirements

Before installing Igniter.js, ensure you have:

- **Node.js** 22.0 or higher
- **Package Manager**: npm, pnpm, yarn, or bun
- **TypeScript** 5.0 or higher (configured in your project)

<Callout type="info" title="TypeScript Required">
  Igniter.js is built with TypeScript-first principles and requires TypeScript for full type safety and autocomplete features.
</Callout>
