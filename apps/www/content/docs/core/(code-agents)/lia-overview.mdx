Lia is the assistant available on the Igniter.js documentation site. It can search the published docs, retrieve a page, and list available pages. It is not a coding-agent package installed by `@igniter-js/core`, and the Core CLI does not install or train IDE agents.

## Documentation tools

The site implementation registers three tools for Lia:

| Tool | Purpose |
|---|---|
| `searchDocs` | Searches the Fumadocs documentation source. |
| `getPageContent` | Retrieves the full content of a documentation page by path. |
| `listPages` | Lists pages and categories available in the documentation source. |

These are tools used by the documentation site's assistant. They are not public Core package APIs.

## Use the docs directly

You can browse the docs, use the site's search, or provide the LLM-friendly endpoints to an assistant that supports remote text sources:

- [`/llms.txt`](https://igniterjs.tryfractal.co/llms.txt) — index of available content.
- [`/llms-full.txt`](https://igniterjs.tryfractal.co/llms-full.txt) — combined content dump.
- [`/llms/docs/full.txt`](https://igniterjs.tryfractal.co/llms/docs/full.txt) — documentation content dump.

For an MCP integration, use the dedicated [MCP Server guide](/docs/mcp-server-cli).
