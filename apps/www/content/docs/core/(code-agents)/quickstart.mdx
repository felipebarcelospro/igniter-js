---
title: Quickstart for AI Assistants
description: Give an AI assistant access to the Igniter.js documentation using the published docs endpoints.
---

Igniter.js does not provide a `lia` subcommand or a CLI flow that installs agent rules. The documentation site publishes text endpoints that an assistant can use as reference material.

## Start with the docs index

Open [`/llms.txt`](https://igniterjs.tryfractal.co/llms.txt) to find the published documentation sections and their links. For a complete text snapshot, use [`/llms-full.txt`](https://igniterjs.tryfractal.co/llms-full.txt).

## Ask focused questions

When using an AI assistant, include the exact documentation route relevant to your question. For example:

```text
Use the Igniter.js Core quick start at https://igniterjs.tryfractal.co/docs/core/quick-start.
Check the documented builder methods before suggesting an API.
```

The site also exposes documentation page content as Markdown at `/llms.mdx/<page-path>`. Check the endpoint response for a specific page rather than assuming that a local CLI has synchronized the docs.

## Optional MCP support

For coding assistants that support MCP, follow the dedicated [MCP Server installation guide](/docs/mcp-server-cli/installation). The MCP server is a separate package from `@igniter-js/core`.
