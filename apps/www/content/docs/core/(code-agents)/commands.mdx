---
title: CLI Commands and Agent Workflows
description: Distinguish Igniter CLI commands from coding-assistant slash commands.
---

The Igniter CLI does not register slash commands such as `/setup`, `/task`, or `/create-rule` in coding assistants. The CLI has its own command tree, documented in the [CLI section](/docs/cli).

## Use the CLI

The CLI currently provides project initialization and code generation workflows. Start with the [CLI command reference](/docs/cli/commands/init) and [generation guide](/docs/cli/commands/generate) for exact flags and generated files.

```bash
npx @igniter-js/cli@latest init
```

The `init` command scaffolds a project through its interactive prompts. Use the package manager and runtime commands generated for your selected template; do not assume every starter shares the same scripts.

## Assistant-specific commands

If your editor supports custom slash commands, define them using that editor's documented format. They are owned by your project/editor configuration and are not installed or synchronized by `@igniter-js/core`.
