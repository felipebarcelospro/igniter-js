---
title: LLM-Friendly Documentation Endpoints
description: Retrieve Igniter.js documentation as an index, combined text, or raw Markdown page.
---

The Igniter.js documentation site serves text endpoints that help AI tools locate and read published content. They are site routes; they do not require a `next.config.ts` rewrite in an application consuming the docs.

## Available endpoints

| Route | Response |
|---|---|
| [`/llms.txt`](https://igniterjs.tryfractal.co/llms.txt) | Content index with page links. |
| [`/llms-full.txt`](https://igniterjs.tryfractal.co/llms-full.txt) | Combined content dump. |
| [`/llms/docs/full.txt`](https://igniterjs.tryfractal.co/llms/docs/full.txt) | Documentation-only text dump. |
| `/llms.mdx/<page-path>.mdx` | Raw Markdown/MDX content for a page. |

The index and dumps are generated by the docs site from its configured content sources. Use the page routes when you need focused context; use the full dump when your tool can handle a larger document.

## Retrieve one page

For example, the Core quick start page is available in the browser at `/docs/core/quick-start`. Its raw text endpoint is:

```text
https://igniterjs.tryfractal.co/llms.mdx/docs/core/quick-start.mdx
```

The exact returned content can change when the documentation is updated. Treat the live response as the current published content.

## Use with an assistant

Provide the index or a specific page URL to an assistant that can fetch remote text. For a local coding assistant integration that uses tools, see the separate [MCP server guide](/docs/mcp-server-cli).
