`@igniter-js/core` does not install or automatically load coding-agent rules. AI assistants that support repository instructions can use files such as `AGENTS.md` or their own documented project-rule format.

## Add instructions to your project

Keep instructions close to the code they govern. Explain the supported runtime, package conventions, commands, and verified examples. Link to the relevant Igniter.js docs instead of copying API details that can become stale.

```md
# Project instructions

- Use the installed package version as the API source of truth.
- Read the relevant Igniter.js guide before changing an integration.
- Keep secrets out of logs and examples.
```

This is plain Markdown guidance; it is not a built-in Igniter.js rule schema. Check your chosen coding assistant's documentation for its supported filenames and matching rules.

## Repository-specific guidance

The Igniter.js monorepo uses its own root and scoped `AGENTS.md` files for contributors. Those files describe repository maintenance and are not copied into projects by installing `@igniter-js/core`.

For published docs that an assistant can read, use the site's [LLM-friendly content endpoints](/docs/core/using-llms-txt).
