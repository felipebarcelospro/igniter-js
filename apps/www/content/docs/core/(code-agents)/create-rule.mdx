title: Write Project Instructions
description: Write clear project guidance for AI coding assistants without relying on an unsupported generator command.
---

There is no Igniter CLI `create-rule` command. You can write project instructions as Markdown and configure your coding assistant to read the supported file format for that tool.

## Keep guidance verifiable

A useful instruction file should:

1. State which package or directory it covers.
2. Point to the package's public exports and source of truth.
3. Include only commands verified in the repository.
4. Link to current docs rather than duplicating long API explanations.
5. Explain security constraints, especially around secrets and user data.

```md
# API package guidance

- Read the package manifest and scoped instructions before changing public APIs.
- Verify examples against the exported types and tests.
- Use the installed package version when checking compatibility.
```

The example is ordinary Markdown, not a special Igniter.js schema. Follow your editor's documentation for filenames, frontmatter, scope, and reload behavior.

For Igniter's own interactive project scaffolding, see the [CLI initialization command](/docs/cli/commands/init).
