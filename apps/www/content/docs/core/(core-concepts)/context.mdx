## What context contains

Core context is the application data made available to action and procedure handlers. Use it for dependencies such as database clients, service objects, and configuration. Request values such as headers, path parameters, and parsed bodies are provided separately on the handler's `request` object.

## Configure runtime context

Pass a value, synchronous factory, or asynchronous factory to `.withContext()`. The factory is evaluated while Core builds the context for request processing, but the current implementation calls it without passing the incoming `Request`.

```typescript
import { Igniter } from '@igniter-js/core';
import { audit } from '@igniter-js/core/plugins';
import { createDatabase } from './database';
import { createEmailService } from './email';

const igniter = Igniter.create()
  .withContext(async () => ({
    db: await createDatabase(),
    email: createEmailService(),
    config: {
      environment: process.env.NODE_ENV ?? 'development',
    },
  }))
  .build();
```

The context factory must return the runtime value handlers need. A type-only context annotation does not construct dependencies.

## Use context in a handler

Handlers receive `context` for application dependencies and `request` for request-specific data:

```typescript
const getUser = igniter.query({
  path: '/users/:id' as const,
  handler: async ({ request, context, response }) => {
    const user = await context.db.users.findUnique({
      where: { id: request.params.id },
    });

    if (!user) return response.notFound('User not found');
    return response.success({ user });
  },
});
```

For authentication, read the credential from `request.headers` in a procedure or action, then return the authenticated user as procedure context for downstream handlers. Do not expect `.withContext()` to receive the request object in the current runtime.

## Add plugins

Core plugins are registered with `.addPlugin()`. Their values are available under `context.$plugins` in handlers; they are not automatically merged into the top-level context object.

```typescript
const igniter = Igniter.create()
  .withContext(async () => ({ db: await createDatabase() }))
  .addPlugin('audit', audit)
  .build();

const listUsers = igniter.query({
  path: '/users',
  handler: async ({ context, response }) => {
    await context.$plugins.audit.actions.create({ action: 'users:list' });
    const users = await context.db.users.findMany();
    return response.success({ users });
  },
});
```

See [Procedures](/docs/core/procedures) for request-aware authentication and [Plugins](/docs/core/plugins) for plugin registration and typing.
