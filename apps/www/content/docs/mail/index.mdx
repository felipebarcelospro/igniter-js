title: "@igniter-js/mail"
description: "Send typed transactional email with schema-validated React Email templates, interchangeable providers, and optional queue scheduling."
---

`@igniter-js/mail` centralizes transactional email configuration and sending. Define a template with a Standard Schema-compatible validator and React renderer; the template key and input type are inferred by `mail.send()`.

The package includes adapters for Resend, Postmark, SendGrid, SMTP, and in-memory testing. Provider changes do not alter the `send()` call. Queue-based delivery is optional and integrates with the job queue adapter from [Core](/docs/core).

<Callout type="warn" title="Server-only">
  Keep mail configuration and send operations on the server. The package's browser entrypoint intentionally throws to prevent accidental client-side use.
</Callout>
