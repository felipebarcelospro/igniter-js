## Prerequisites

- **Node.js** 22+ or **Bun** runtime
- **Redis** server (local or remote) — for production use
- **TypeScript** 5.6+ (recommended for full type inference)

<Callout type="info">
  Don't have Redis? Use the built-in memory adapter for development, testing, or desktop apps (Electron, Tauri, Bun).
</Callout>

## Redis Setup

### Local Development

Run Redis with Docker:

```bash
docker run -d -p 6379:6379 redis:7-alpine
```

Or install natively:

**macOS:**
```bash
brew install redis && brew services start redis
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install redis-server && sudo systemctl start redis
```

Verify it's running:

```bash
redis-cli ping
# PONG
```

### Production

Use a managed Redis service:

- **Redis Cloud** (redis.com/cloud)
- **AWS ElastiCache**
- **Google Cloud Memorystore**
- **Azure Cache for Redis**

## Create Your Store (60 seconds)

```typescript
// src/store.ts
import Redis from "ioredis";
import { IgniterStore } from "@igniter-js/store";
import { IgniterStoreRedisAdapter } from "@igniter-js/store/adapters";

const redis = new Redis(process.env.REDIS_URL);

export const store = IgniterStore.create()
  .withAdapter(IgniterStoreRedisAdapter.create({ redis }))
  .withService("api")  // Used in key prefixes for isolation
  .build();
```

**That's it.** Your store is ready.

```typescript
// Use it anywhere
await store.kv.set("user:123", { name: "Avery" }, { ttl: 3600 });
const user = await store.kv.get("user:123");
console.log(user?.name); // "Avery"
```

## Redis Connection Options

```typescript
import Redis from "ioredis";

const redis = new Redis({
  host: process.env.REDIS_HOST || "localhost",
  port: Number(process.env.REDIS_PORT) || 6379,
  password: process.env.REDIS_PASSWORD,
  db: Number(process.env.REDIS_DB) || 0,

  // Retry strategy
  retryStrategy: (times) => {
    const delay = Math.min(times * 50, 2000);
    return delay;
  },
  maxRetriesPerRequest: 3,

  // Resilience
  enableOfflineQueue: true,
  lazyConnect: false,
});

// Connection events
redis.on("connect", () => console.log("Redis connected"));
redis.on("error", (err) => console.error("Redis error:", err));
```

### Redis Cluster

```typescript
import { Cluster } from "ioredis";

const cluster = new Cluster(
  [
    { host: "127.0.0.1", port: 7000 },
    { host: "127.0.0.1", port: 7001 },
    { host: "127.0.0.1", port: 7002 },
  ],
  {
    redisOptions: { password: process.env.REDIS_PASSWORD },
  }
);

const adapter = IgniterStoreRedisAdapter.create({ redis: cluster });
```

### Using a Redis URL

```typescript
const redis = new Redis(process.env.REDIS_URL);
// redis://user:pass@localhost:6379/0
```

## Memory Adapter (No Redis Required)

For development, testing, or environments where Redis isn't available:

```typescript
import { IgniterStore } from "@igniter-js/store";
import { IgniterStoreMemoryAdapter } from "@igniter-js/store/adapters";

const store = IgniterStore.create()
  .withAdapter(IgniterStoreMemoryAdapter.create())
  .withService("dev")
  .build();

// Same API — now backed by in-memory storage
await store.kv.set("key", "value");
const val = await store.kv.get("key");
```

<Callout type="success" title="Seamless swap">
  The memory adapter implements the full `IgniterStoreAdapter` contract — KV, counters, claims, batch, pub/sub, streams, and scan. Swap adapters without changing any business logic.
</Callout>

## Sharing a Redis Connection

Share the same Redis client across multiple adapters or packages:

```typescript
import Redis from "ioredis";
import { IgniterStoreRedisAdapter } from "@igniter-js/store/adapters";

// Single Redis client
export const redis = new Redis(process.env.REDIS_URL);

// Store adapter
export const storeAdapter = IgniterStoreRedisAdapter.create({ redis });

// The store internally duplicates the client for subscriptions
```

<Callout type="info">
  The Redis adapter creates an internal duplicate client for Pub/Sub subscriptions (Redis requirement). Your main `redis` client remains dedicated to commands.
</Callout>

## Health Check

Verify connectivity at startup:

```typescript
async function checkStoreHealth(store: IgniterStoreManager) {
  try {
    await store.kv.set("health:check", "ok", { ttl: 10 });
    const result = await store.kv.get("health:check");
    return result === "ok";
  } catch {
    return false;
  }
}
```
