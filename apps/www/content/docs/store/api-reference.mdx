## Overview

This document provides the complete API reference for `@igniter-js/store`. Every method and type documented here reflects the actual implementation.

---

## IgniterStore — Builder

The entry point is `IgniterStore.create()` which returns an `IgniterStoreBuilder`.

### `static create()`

Creates a new builder instance.

```typescript
const builder = IgniterStore.create();
```

### `withAdapter(adapter)`

Sets the storage adapter. **Required.**

| Parameter | Type | Description |
|-----------|------|-------------|
| `adapter` | `IgniterStoreAdapter` | The adapter instance |

```typescript
.withAdapter(IgniterStoreRedisAdapter.create({ redis }))
```

### `withService(service)`

Sets the service name for key prefix isolation. **Required.**

| Parameter | Type | Description |
|-----------|------|-------------|
| `service` | `string` | Service name (e.g., `"api"`, `"worker"`) |

```typescript
.withService("my-api")
```

### `withSerializer(serializer)`

Sets a custom serializer.

| Parameter | Type | Description |
|-----------|------|-------------|
| `serializer` | `IgniterStoreSerializer` | Object with `encode` and `decode` |

```typescript
.withSerializer({
  encode: (value) => JSON.stringify(value),
  decode: (value) => JSON.parse(value),
})
```

### `withLogger(logger)`

Sets a logger instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `logger` | `IgniterLogger` | Logger with `info`, `warn`, `error`, `debug` |

### `withTelemetry(telemetry)`

Sets the telemetry manager for observability.

| Parameter | Type | Description |
|-----------|------|-------------|
| `telemetry` | `IgniterTelemetryManager<any>` | Telemetry instance from `@igniter-js/telemetry` |

### `addScope(key, options?)`

Adds a typed scope definition.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | Scope key (e.g., `"organization"`) |
| `options.required` | `boolean?` | Whether scope is required (default: `true`) |
| `options.description` | `string?` | Human-readable description |

```typescript
.addScope("organization", { required: true, description: "Tenant org" })
.addScope("workspace")
```

### `addEvents(events, validation?)`

Adds typed events for a namespace.

| Parameter | Type | Description |
|-----------|------|-------------|
| `events` | `{ namespace, events }` | Built with `IgniterStoreEvents.create().build()` |
| `validation.validatePublish` | `boolean?` | Validate when publishing (default: `true`) |
| `validation.validateSubscribe` | `boolean?` | Validate when subscribing (default: `false`) |
| `validation.throwOnValidationError` | `boolean?` | Throw on invalid payload (default: `true`) |

```typescript
.addEvents(UserEvents, {
  validatePublish: true,
  validateSubscribe: false,
  throwOnValidationError: true,
})
```

### `build()`

Builds and returns the `IgniterStoreManager` instance.

```typescript
const store = builder.build();
```

## IgniterStoreManager

The runtime store instance returned by `.build()`.

### Namespaced Operations

| Property | Type | Purpose |
|----------|------|---------|
| `store.kv` | `IgniterStoreKV` | Key-value operations |
| `store.counter` | `IgniterStoreCounter` | Atomic counters |
| `store.claim` | `IgniterStoreClaim` | Distributed claims (locks) |
| `store.batch` | `IgniterStoreBatch` | Multi-key operations |
| `store.events` | `IgniterStoreEventsManager` | Pub/Sub (string + proxy APIs) |
| `store.streams` | `IgniterStoreStreams` | Redis Streams |
| `store.dev` | `IgniterStoreDev` | Development/debugging tools |
| `store.logger` | `IgniterLogger \| undefined` | Logger instance |

### `scope(scopeKey, identifier)`

Creates a scoped store instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `scopeKey` | `string` | Scope key (type-safe if defined via `addScope()`) |
| `identifier` | `string \| number` | Scope identifier |

Returns: `IgniterStoreManager` — a new scoped instance with auto-prefixed keys.

## Key-Value (`store.kv`)

### `get<T>(key)`

Retrieves a value.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The key to retrieve |

Returns: `Promise<T | null>`

```typescript
const user = await store.kv.get<User>("user:123");
```

### `set(key, value, options?)`

Stores a value.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The key |
| `value` | `unknown` | The value (JSON-serializable) |
| `options.ttl` | `number?` | TTL in seconds |

Returns: `Promise<void>`

```typescript
await store.kv.set("user:123", { name: "Avery" }, { ttl: 3600 });
```

### `remove(key)`

Deletes a key.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The key to delete |

Returns: `Promise<void>`

### `exists(key)`

Checks if a key exists.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The key to check |

Returns: `Promise<boolean>`

### `expire(key, ttlSeconds)`

Sets a TTL on an existing key.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The key |
| `ttlSeconds` | `number` | TTL in seconds |

Returns: `Promise<void>`

### `touch(key, ttlSeconds)`

Updates a key's TTL (like `expire`, signals access).

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The key |
| `ttlSeconds` | `number` | TTL in seconds |

Returns: `Promise<void>`

## Counter (`store.counter`)

### `increment(key)`

Atomically increments a counter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The counter key |

Returns: `Promise<number>` — new value after increment

```typescript
const views = await store.counter.increment("page-views"); // → 1
```

### `decrement(key)`

Atomically decrements a counter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The counter key |

Returns: `Promise<number>` — new value after decrement

```typescript
const remaining = await store.counter.decrement("stock"); // → -1
```

### `expire(key, ttlSeconds)`

Sets TTL on a counter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The counter key |
| `ttlSeconds` | `number` | TTL in seconds |

Returns: `Promise<void>`

## Claim (`store.claim`)

### `once(key, value, options?)`

Acquires a distributed lock using SETNX.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | The claim key |
| `value` | `unknown` | Owner identifier |
| `options.ttl` | `number?` | Auto-expire after N seconds |

Returns: `Promise<boolean>` — `true` if acquired, `false` if already held

```typescript
const claimed = await store.claim.once("job:cleanup", "worker-1", { ttl: 30 });
```

## Batch (`store.batch`)

### `get<T>(keys)`

Retrieves multiple values.

| Parameter | Type | Description |
|-----------|------|-------------|
| `keys` | `string[]` | Array of keys |

Returns: `Promise<(T | null)[]>` — values in same order, `null` for missing

```typescript
const users = await store.batch.get<User>(["user:1", "user:2", "user:3"]);
```

### `set(entries)`

Stores multiple values.

| Parameter | Type | Description |
|-----------|------|-------------|
| `entries` | `Array<{ key: string; value: unknown; ttl?: number }>` | Key-value entries |

Returns: `Promise<void>`

```typescript
await store.batch.set([
  { key: "user:1", value: { name: "Alice" }, ttl: 3600 },
  { key: "user:2", value: { name: "Bob" } },
]);
```

## Events (`store.events`)

`store.events` exposes both string-based and proxy-based APIs.

### String-Based API

**`publish(event, message)`**

| Parameter | Type | Description |
|-----------|------|-------------|
| `event` | `string` | Event name (e.g., `"user:created"`) |
| `message` | (typed) | Payload (typed from schema) |

Returns: `Promise<void>`

**`subscribe(event, handler)`**

| Parameter | Type | Description |
|-----------|------|-------------|
| `event` | `string` | Event name or wildcard (`"user:*"`, `"*"`) |
| `handler` | `(ctx: IgniterStoreEventContext) => void \| Promise<void>` | Callback |

Returns: `Promise<IgniterStoreUnsubscribeFn>`

### Proxy-Based API

For each registered event, `store.events.namespace.eventName` provides:

**`.publish(message)`** — Publish a message (typed).

**`.subscribe(handler)`** — Subscribe to the event (typed context). Returns unsubscribe function.

### IgniterStoreEventContext

| Field | Type | Description |
|-------|------|-------------|
| `type` | `string` | Full event name |
| `data` | `TPayload` | Event payload |
| `timestamp` | `string` | ISO 8601 timestamp |
| `scope?` | `{ key: string; identifier: string }` | Current scope if scoped |

## Streams (`store.streams`)

### `append(stream, message, options?)`

Appends to a stream.

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream` | `string` | Stream name |
| `message` | `unknown` | Message payload |
| `options.maxLen` | `number?` | Max stream length |
| `options.approximate` | `boolean?` | Use ~ for trimming |

Returns: `Promise<string>` — message ID

### `group(group, consumer)`

Creates a consumer in a consumer group.

| Parameter | Type | Description |
|-----------|------|-------------|
| `group` | `string` | Group name |
| `consumer` | `string` | Consumer name |

Returns: `IgniterStoreStreamConsumerGroup`

**Consumer Group Methods:**

- **`ensure(stream, options?)`** — Create group (idempotent)
- **`read<T>(stream, options?)`** — Read messages
- **`ack(stream, ids)`** — Acknowledge messages

### `range<T>(stream, options?)`

Reads a range of messages.

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream` | `string` | Stream name |
| `options.startId` | `string?` | Start ID (default: `"-"`) |
| `options.endId` | `string?` | End ID (default: `"+"`) |
| `options.count` | `number?` | Max messages |
| `options.reverse` | `boolean?` | Reverse order |

Returns: `Promise<IgniterStoreStreamMessage<T>[]>`

## Dev Tools (`store.dev`)

### `scan(pattern, options?)`

Scans keys matching a pattern.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pattern` | `string` | Pattern (e.g., `"user:*"`) |
| `options.cursor` | `string?` | Pagination cursor (default: `"0"`) |
| `options.count` | `number?` | Keys per iteration (default: 10) |

Returns: `Promise<{ keys: string[]; cursor: string }>`

```typescript
const { keys, cursor } = await store.dev.scan("user:*", { count: 100 });
```

## IgniterStoreEvents

### `static create(namespace)`

Creates a new events builder for a namespace.

| Parameter | Type | Description |
|-----------|------|-------------|
| `namespace` | `string` | Unique namespace (e.g., `"user"`) |

### `event(name, schema)`

Adds an event with a Zod/StandardSchemaV1 schema.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Event name (no dots/colons) |
| `schema` | `StandardSchemaV1` | Zod schema for the payload |

### `group(name, builder)`

Creates a nested group of events.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Group name (prefix) |
| `builder` | `(group: IgniterStoreEventsGroupBuilder) => IgniterStoreEventsGroupBuilder` | Group config function |

### `build()`

Returns the events descriptor for `addEvents()`.

Returns: `{ namespace: string; events: IgniterStoreEventsDirectory }`

## Error Codes

All errors extend `IgniterStoreError` (which extends `IgniterError`).

### Configuration Errors

| Code | Message |
|------|---------|
| `STORE_ADAPTER_REQUIRED` | Adapter not configured |
| `STORE_SERVICE_REQUIRED` | Service name not configured |
| `STORE_CONFIGURATION_INVALID` | Invalid configuration |

### Scope Errors

| Code | Message |
|------|---------|
| `STORE_SCOPE_KEY_REQUIRED` | Scope key is required |
| `STORE_SCOPE_IDENTIFIER_REQUIRED` | Scope identifier is required |
| `STORE_INVALID_SCOPE_KEY` | Scope key not defined |
| `STORE_DUPLICATE_SCOPE` | Scope already defined |

### Namespace & Event Errors

| Code | Message |
|------|---------|
| `STORE_MISSING_NAMESPACE` | Events namespace required |
| `STORE_INVALID_NAMESPACE` | Invalid namespace format |
| `STORE_RESERVED_NAMESPACE` | Reserved prefix used |
| `STORE_DUPLICATE_NAMESPACE` | Namespace already registered |
| `STORE_INVALID_EVENT_NAME` | Invalid event name |
| `STORE_DUPLICATE_EVENT` | Event/group already defined |

### Schema Errors

| Code | Message |
|------|---------|
| `STORE_SCHEMA_VALIDATION_FAILED` | Payload doesn't match schema |
| `STORE_SCHEMA_CHANNEL_NOT_FOUND` | Channel not found in registry |

### Operation Errors

| Code | Message |
|------|---------|
| `STORE_OPERATION_FAILED` | Generic operation failure |
| `STORE_GET_FAILED` | Get operation failed |
| `STORE_SET_FAILED` | Set operation failed |
| `STORE_DELETE_FAILED` | Delete operation failed |
| `STORE_INCREMENT_FAILED` | Increment failed |
| `STORE_PUBLISH_FAILED` | Publish failed |
| `STORE_SUBSCRIBE_FAILED` | Subscribe failed |

### Batch Errors

| Code | Message |
|------|---------|
| `STORE_BATCH_FAILED` | Batch operation failed |
| `STORE_BATCH_KEYS_REQUIRED` | Keys array is required |
| `STORE_BATCH_ENTRIES_REQUIRED` | Entries array is required |

### Claim Errors

| Code | Message |
|------|---------|
| `STORE_CLAIM_FAILED` | Claim operation failed |

### Stream Errors

| Code | Message |
|------|---------|
| `STORE_STREAM_APPEND_FAILED` | Stream append failed |
| `STORE_STREAM_READ_FAILED` | Stream read failed |
| `STORE_STREAM_GROUP_CREATE_FAILED` | Group creation failed |
| `STORE_STREAM_ACK_FAILED` | Acknowledgment failed |
| `STORE_STREAM_NAME_REQUIRED` | Stream name required |
| `STORE_STREAM_GROUP_REQUIRED` | Group name required |
| `STORE_STREAM_CONSUMER_REQUIRED` | Consumer name required |

### Serialization Errors

| Code | Message |
|------|---------|
| `STORE_SERIALIZATION_FAILED` | Value serialization failed |
| `STORE_DESERIALIZATION_FAILED` | Value deserialization failed |

### Connection Errors

| Code | Message |
|------|---------|
| `STORE_CONNECTION_FAILED` | Connection failed |
| `STORE_NOT_CONNECTED` | Not connected to backend |

### Error Handling

```typescript
import { IgniterStoreError } from "@igniter-js/store";

try {
  await store.kv.get("key");
} catch (error) {
  if (IgniterStoreError.is(error)) {
    console.log(error.code);     // e.g., "STORE_GET_FAILED"
    console.log(error.message);  // Human-readable message
    console.log(error.statusCode); // HTTP status code
  }
}
```

## Telemetry

### IgniterStoreTelemetryEvents

```typescript
import { IgniterStoreTelemetryEvents } from "@igniter-js/store/telemetry";
```

Returns a typed events registry for `@igniter-js/telemetry`. Use with:

```typescript
const telemetry = IgniterTelemetry.create()
  .withService("api")
  .addEvents(IgniterStoreTelemetryEvents)
  .build();
```

Events span every operation namespace: `igniter.store.kv.*`, `igniter.store.counter.*`, `igniter.store.batch.*`, `igniter.store.claim.*`, `igniter.store.events.*`, `igniter.store.stream.*`, `igniter.store.dev.*`.
