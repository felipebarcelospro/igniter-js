## Overview

Beyond key-value storage, `@igniter-js/store` provides atomic operations for counters, distributed claims (locks), batch reads/writes, and dev utilities for scanning keys.

| Namespace | Purpose | Backed by |
|-----------|---------|-----------|
| `store.counter` | Atomic increment/decrement | `INCR` / `DECR` |
| `store.claim` | Distributed locks | `SETNX` |
| `store.batch` | Multi-key get/set | `MGET` / `MSET` / Pipeline |
| `store.dev` | Debugging & scanning | `SCAN` |

## Counters (`store.counter`)

### Increment

Atomically increments a numeric counter. If the key doesn't exist, it's initialized to 0 before incrementing.

```typescript
const views = await store.counter.increment("page-views");
// First call → 1, second call → 2, third → 3 ...
```

### Decrement

```typescript
const remaining = await store.counter.decrement("available-slots");
// First call → -1, second call → -2 ...
```

### Counter with TTL

Set expiration on counters for periodic resets:

```typescript
const count = await store.counter.increment("daily-views");
if (count === 1) {
  // First hit of the day — set 24h expiration
  await store.counter.expire("daily-views", 86400);
}
```

## Rate Limiting

Build a rate limiter in a few lines:

```typescript
async function checkRateLimit(
  identifier: string,
  limit: number,
  windowSeconds: number,
): Promise<{ allowed: boolean; remaining: number }> {
  const key = `rate:${identifier}`;
  const count = await store.counter.increment(key);

  if (count === 1) {
    await store.counter.expire(key, windowSeconds);
  }

  if (count > limit) {
    return { allowed: false, remaining: 0 };
  }

  return { allowed: true, remaining: limit - count };
}

// Usage — 100 requests per 60 seconds per IP
const { allowed, remaining } = await checkRateLimit(req.ip, 100, 60);
if (!allowed) {
  throw new Error("Rate limit exceeded");
}
```

### Sliding Window Rate Limiting

For more precise limiting:

```typescript
async function slidingWindowRateLimit(
  identifier: string,
  limit: number,
  windowSeconds: number,
) {
  const now = Date.now();
  const windowKey = Math.floor(now / (windowSeconds * 1000));
  const key = `rate:sliding:${identifier}:${windowKey}`;

  const currentCount = await store.counter.increment(key);
  if (currentCount === 1) {
    await store.counter.expire(key, windowSeconds * 2);
  }

  // Check previous window
  const prevKey = `rate:sliding:${identifier}:${windowKey - 1}`;
  const prevCount = await store.kv.get<number>(prevKey) ?? 0;

  // Weighted count
  const weight = (now % (windowSeconds * 1000)) / (windowSeconds * 1000);
  const total = currentCount + prevCount * (1 - weight);

  return {
    allowed: total <= limit,
    remaining: Math.max(0, Math.floor(limit - total)),
  };
}
```

## Claims — Distributed Locks (`store.claim`)

`store.claim.once()` uses `SETNX` to atomically acquire a lock. Returns `true` if acquired, `false` if already held.

```typescript
const claimed = await store.claim.once(
  "job:cleanup",        // Lock key
  "worker-1",           // Owner identifier
  { ttl: 30 }           // Auto-expire after 30 seconds
);

if (claimed) {
  try {
    await performCleanup();
  } finally {
    await store.kv.remove("job:cleanup"); // Release
  }
}
```

### Leader Election for Cron Jobs

```typescript
async function runCronJob(jobName: string, fn: () => Promise<void>) {
  const lockKey = `cron:${jobName}`;
  const isLeader = await store.claim.once(lockKey, process.env.HOSTNAME!, { ttl: 55 });

  if (!isLeader) {
    console.log(`[${jobName}] Another instance is running. Skipping.`);
    return;
  }

  try {
    await fn();
  } finally {
    await store.kv.remove(lockKey);
  }
}

// Usage — only one instance runs this per minute
setInterval(() => runCronJob("cleanup", performCleanup), 60_000);
```

### Job Deduplication

```typescript
async function processJobOnce(jobId: string, fn: () => Promise<void>) {
  const key = `job:processed:${jobId}`;
  const acquired = await store.claim.once(key, "processor", { ttl: 86400 });

  if (!acquired) {
    return; // Already processed
  }

  await fn();
}
```

## Batch Operations (`store.batch`)

### Batch Get

```typescript
const users = await store.batch.get<User>([
  "user:1",
  "user:2",
  "user:3",
]);

// users = [User | null, User | null, User | null]
// null for missing keys
```

### Batch Set

```typescript
await store.batch.set([
  { key: "user:1", value: { name: "Alice" }, ttl: 3600 },
  { key: "user:2", value: { name: "Bob" }, ttl: 3600 },
  { key: "user:3", value: { name: "Charlie" } },
]);
```

<Callout type="success" title="Performance">
  Batch operations use Redis `MGET`/`MSET` or pipelines under the hood, drastically reducing round-trips compared to individual calls.
</Callout>

### Cache Warming

```typescript
async function warmPopularUsersCache(userIds: string[]) {
  const users = await db.user.findMany({
    where: { id: { in: userIds } },
  });

  await store.batch.set(
    users.map((user) => ({
      key: `user:${user.id}`,
      value: user,
      ttl: 3600,
    }))
  );
}
```

## Dev Tools (`store.dev`)

### Scanning Keys

```typescript
// Scan all user keys
const result = await store.dev.scan("user:*");
console.log(result.keys);  // ["user:1", "user:2", ...]
console.log(result.cursor); // "0" if scan is complete

// Paginated scan
let cursor = "0";
do {
  const { keys, cursor: nextCursor } = await store.dev.scan("user:*", {
    cursor,
    count: 100,
  });
  console.log("Found:", keys);
  cursor = nextCursor;
} while (cursor !== "0");
```

### Cleaning Up by Pattern

```typescript
async function deleteByPattern(pattern: string) {
  let cursor = "0";
  do {
    const result = await store.dev.scan(pattern, { cursor, count: 100 });
    for (const key of result.keys) {
      await store.kv.remove(key);
    }
    cursor = result.cursor;
  } while (cursor !== "0");
}

// Delete all cache keys for a tenant
await deleteByPattern("igniter:store:api:organization:org_123:*");
```

## Real-World Examples

### Request Counter per Endpoint

```typescript
async function trackEndpointHit(endpoint: string) {
  const today = new Date().toISOString().split("T")[0];
  const key = `metrics:${endpoint}:${today}`;

  const count = await store.counter.increment(key);
  if (count === 1) {
    // Expire at midnight
    const tomorrow = new Date();
    tomorrow.setDate(tomorrow.getDate() + 1);
    tomorrow.setHours(0, 0, 0, 0);
    const ttl = Math.floor((tomorrow.getTime() - Date.now()) / 1000);
    await store.counter.expire(key, ttl);
  }

  return count;
}
```

### Inventory Reservation

```typescript
async function reserveInventory(productId: string, quantity: number) {
  const key = `inventory:${productId}`;
  const available = await store.counter.decrement(key);

  if (available < 0) {
    // Rollback — not enough stock
    await store.counter.increment(key);
    throw new Error("Insufficient inventory");
  }

  return available;
}
```

### Feature Flag with Percentage Rollout

```typescript
async function isInRolloutGroup(
  feature: string,
  userId: string,
  percentage: number,
): Promise<boolean> {
  // Deterministic hash of userId
  const hash = hashCode(`${feature}:${userId}`);
  return (hash % 100) < percentage;
}
```
