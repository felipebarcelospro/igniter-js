## Views

Views are first-class, global objects that define how data is fetched, rendered, and interacted with. They live alongside collections and have unrestricted access to the full manager via the `withData` hook.

Each view carries a **json-render `Spec`** (`root`, `elements`, optional `state`) that client renderers (e.g. `@json-render/react`) consume directly.

---

## View Anatomy

A view has four core parts:

```typescript
import { IgniterCollectionView } from '@igniter-js/collections';

const DashboardView = IgniterCollectionView.create('dashboard')
  .withTitle('Analytics Dashboard')
  .withDescription('Key metrics and KPIs')
  .withMetadata({ icon: 'chart', order: 1 })
  .withData(async ({ manager }) => {
    const posts = await manager.posts.findMany();
    return { posts, total: posts.length };
  })
  .withSpec({
    root: 'stack',
    elements: {
      stack: {
        type: 'Stack',
        props: { direction: 'vertical', gap: 'md', align: null, justify: null },
        children: ['metric', 'table'],
      },
      metric: {
        type: 'Metric',
        props: {
          label: 'Total',
          value: { $state: '/total' },
          format: 'number',
        },
        children: [],
      },
      table: {
        type: 'Table',
        props: { data: { $state: '/posts' } },
        children: [],
      },
    },
  })
  .addAction('export', {
    description: 'Export to CSV',
    handler: async ({ manager, params }) => ({ success: true }),
  })
  .build();
```

## The Data Hook (`withData`)

The heart of every view. Receives the full `IIgniterCollectionsManager` and returns **state fragments** merged into `spec.state` at render time:

```typescript
.withData(async ({ manager }) => {
  const [posts, pages, authors] = await Promise.all([
    manager.posts.findMany({ where: { published: true }, take: 10 }),
    manager.pages.findMany({ take: 20 }),
    manager.authors.count(),
  ]);

  return {
    recentPosts: posts,
    pages,
    authorCount: authors,
    lastUpdated: new Date().toISOString(),
  };
})
```

Bind UI to state with json-render expressions such as `{ $state: '/totalPosts' }` in element `props`. The hook return object is deep-merged into `spec.state` when the view is rendered.

## The UI Spec (`withSpec`)

Views use the [json-render](https://github.com/vercel-labs/json-render) format: a flat `elements` map, a `root` key, and optional default `state`. Data bindings use `$state` expressions (JSON Pointer paths into `spec.state`):

```typescript
.withSpec({
  root: 'overview',
  elements: {
    overview: {
      type: 'Stack',
      props: { direction: 'vertical', gap: 'lg', align: null, justify: null },
      children: ['metrics', 'recent'],
    },
    metrics: {
      type: 'Stack',
      props: { direction: 'horizontal', gap: 'md', align: null, justify: null },
      children: ['totalPosts', 'totalPages', 'totalAuthors'],
    },
    totalPosts: {
      type: 'Metric',
      props: {
        label: 'Total Posts',
        value: { $state: '/totalPosts' },
        format: 'number',
      },
      children: [],
    },
    totalPages: {
      type: 'Metric',
      props: {
        label: 'Pages',
        value: { $state: '/totalPages' },
        format: 'number',
      },
      children: [],
    },
    totalAuthors: {
      type: 'Metric',
      props: {
        label: 'Authors',
        value: { $state: '/totalAuthors' },
        format: 'number',
      },
      children: [],
    },
    recent: {
      type: 'Table',
      props: { data: { $state: '/recentPosts' } },
      children: [],
    },
  },
})
```

<Callout type="info">
  `withSpec` is validated at `build()` (structure) and again after state merge at `render()` (full spec). Component `type` values must match your client component catalog.
</Callout>

## Actions (`addAction`)

Actions are executable functions bound to a view. They receive the manager, request params, and optional user context:

```typescript
const DashboardView = IgniterCollectionView.create('dashboard')
  .withData(async ({ manager }) => {
    const posts = await manager.posts.findMany({ take: 50 });
    return { posts, total: posts.length };
  })
  .addAction('export', {
    description: 'Export posts to CSV',
    handler: async ({ manager, params }) => {
      const { format = 'csv' } = params as { format?: string };
      const posts = await manager.posts.findMany();

      if (format === 'csv') {
        const csv = convertToCSV(posts);
        return { success: true, data: csv, contentType: 'text/csv' };
      }

      return { success: true, data: posts, contentType: 'application/json' };
    },
  })
  .addAction('publishAll', {
    description: 'Publish all draft posts',
    handler: async ({ manager }) => {
      const drafts = await manager.posts.findMany({
        where: { published: false },
      });

      for (const draft of drafts) {
        await manager.posts.update({
          where: { id: draft.id },
          data: { published: true },
        });
      }

      return { success: true, count: drafts.length };
    },
  })
  .build();
```

Action handlers may return `updates` — JSON Pointer patches applied to `spec.state` on the client:

```typescript
.addAction('increment', {
  description: 'Bump counter',
  handler: async () => ({
    success: true,
    updates: { '/count': 1 },
  }),
})
```

### Action Context

| Field | Type | Description |
|-------|------|-------------|
| `manager` | `IIgniterCollectionsManager` | Full access to all collections |
| `params` | `Record<string, unknown>` | Parameters from the action call |
| `context` | `unknown` | User-defined context from `withContext()` |

## Rendering Views

Views are registered on the manager and can be rendered programmatically:

```typescript
const docs = IgniterCollections.create()
  .withAdapter(new NodeFsAdapter())
  .addCollection(Posts)
  .addView(DashboardView)
  .build();

const result = await docs.views.render('dashboard');

console.log(result.spec);           // Full json-render Spec (structure + merged state)
console.log(result.spec.state);     // State from getData merged into spec
console.log(result.view.metadata);  // { icon, order, ... }
console.log(result.renderedAt);     // ISO timestamp

const actionResult = await docs.views.execute('dashboard', 'export', {
  format: 'csv',
});
```

Pass `result.spec` to a json-render client `<Renderer spec={result.spec} />`.

## Programmatic vs Watched Views

Views can be defined two ways:

### Programmatic (Builder API)

```typescript
const view = IgniterCollectionView.create('dashboard')
  .withData(async ({ manager }) => ({ items: [] }))
  .withSpec({
    root: 'root',
    elements: {
      root: {
        type: 'Table',
        props: { data: { $state: '/items' } },
        children: [],
      },
    },
  })
  .build();

docs.addView(view);
```

### File-Based (Auto-Discovery)

```typescript
// .fractal/views/dashboard.view.ts
export default {
  name: 'dashboard',
  title: 'Dashboard',
  getData: async ({ manager }) => {
    const posts = await manager.posts.findMany();
    return { posts };
  },
  spec: {
    root: 'root',
    elements: {
      root: {
        type: 'Table',
        props: { data: { $state: '/posts' } },
        children: [],
      },
    },
  },
};
```

```typescript
const docs = IgniterCollections.create()
  .withAdapter(new NodeFsAdapter())
  .withWatcher('.fractal', { views: '*.view.{ts,json}' })
  .build();

// Views auto-discovered from .fractal/views/*.view.ts
```

Programmatic views take precedence over watched views when there's a name conflict. Legacy `tree` fields in view files are rejected.

## Real-World Example: Content Dashboard

```typescript
const ContentDashboard = IgniterCollectionView.create('content-dashboard')
  .withTitle('Content Dashboard')
  .withDescription('Overview of all content across collections')
  .withMetadata({ icon: 'layout-dashboard', order: 1 })
  .withData(async ({ manager }) => {
    const [posts, pages, drafts, featuredPosts] = await Promise.all([
      manager.posts.findMany({
        orderBy: { createdAt: 'desc' as const },
        take: 10,
        select: { id: true, title: true, author: true, published: true, createdAt: true },
      }),
      manager.pages.count(),
      manager.posts.count({ where: { published: false } }),
      manager.posts.findMany({
        where: { published: true, featured: true },
        take: 5,
      }),
    ]);

    return {
      totalPosts: await manager.posts.count(),
      totalPages: pages,
      draftCount: drafts,
      recentPosts: posts,
      featuredPosts,
      lastUpdated: new Date().toISOString(),
    };
  })
  .withSpec({
    root: 'dashboard',
    elements: {
      dashboard: {
        type: 'Stack',
        props: { direction: 'vertical', gap: 'lg', align: null, justify: null },
        children: ['overview', 'featured', 'recent'],
      },
      overview: {
        type: 'Stack',
        props: { direction: 'horizontal', gap: 'md', align: null, justify: null },
        children: ['totalPosts', 'totalPages', 'draftCount'],
      },
      totalPosts: {
        type: 'Metric',
        props: { label: 'Total Posts', value: { $state: '/totalPosts' }, format: 'number' },
        children: [],
      },
      totalPages: {
        type: 'Metric',
        props: { label: 'Pages', value: { $state: '/totalPages' }, format: 'number' },
        children: [],
      },
      draftCount: {
        type: 'Metric',
        props: { label: 'Drafts', value: { $state: '/draftCount' }, format: 'number' },
        children: [],
      },
      featured: {
        type: 'Table',
        props: { data: { $state: '/featuredPosts' } },
        children: [],
      },
      recent: {
        type: 'Table',
        props: { data: { $state: '/recentPosts' } },
        children: [],
      },
    },
  })
  .addAction('createPost', {
    description: 'Create a new draft post',
    handler: async ({ manager, params }) => {
      const { title, author } = params as { title: string; author: string };
      const post = await manager.posts.create({
        data: {
          title,
          author,
          published: false,
          tags: [],
        },
      });
      return { success: true, post };
    },
  })
  .build();
```
