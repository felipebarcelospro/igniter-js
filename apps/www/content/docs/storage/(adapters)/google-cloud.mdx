## Credentials and Environment

Provide service account credentials as raw JSON or base64-encoded JSON, plus bucket details. Set environment variables or pass credentials directly. If credentials are omitted, the Google Cloud client uses its normal default credential resolution.

<TypeTable
  type={{
    IGNITER_STORAGE_GOOGLE_BUCKET: {
      type: "string",
      description: "Bucket name",
      required: true,
    },
    IGNITER_STORAGE_GOOGLE_CREDENTIALS_JSON: {
      type: "string",
      description: "Raw JSON credentials",
      required: false,
    },
    IGNITER_STORAGE_GOOGLE_CREDENTIALS_JSON_BASE64: {
      type: "string",
      description: "Base64-encoded credentials JSON",
      required: false,
    },
  }}
/>

## Minimal Setup

```typescript
import { IgniterStorage } from "@igniter-js/storage";

export const storage = IgniterStorage.create()
  .withAdapter("google", {
    bucket: process.env.IGNITER_STORAGE_GOOGLE_BUCKET!,
    credentialsJson: process.env.IGNITER_STORAGE_GOOGLE_CREDENTIALS_JSON,
    credentialsJsonBase64:
      process.env.IGNITER_STORAGE_GOOGLE_CREDENTIALS_JSON_BASE64,
  })
  .withUrl(process.env.IGNITER_STORAGE_URL || "https://cdn.example.com")
  .build();
```

<Callout type="warn" title="Public access">
  Ensure the bucket policy/IAM allows public reads if you rely on CDN-style
  URLs. Otherwise, pair this adapter with signed URLs at your CDN or edge layer.
</Callout>

## Authentication and Paths

When credentials are omitted, the adapter creates the Google Cloud client without explicit credentials, so the SDK uses Application Default Credentials. Use `.withPath('/staging')` to isolate environments in the same bucket while keeping URLs stable (`https://cdn.example.com/staging/...`).

<Callout type="warn">
  The adapter's credential type and environment parser accept `region` and
  `endpoint` values, but the current client factory does not pass either value
  to `@google-cloud/storage`. These settings do not configure a custom endpoint
  or emulator.
</Callout>
