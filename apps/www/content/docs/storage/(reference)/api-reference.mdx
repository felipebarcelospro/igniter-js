## Public exports

The package root exports `IgniterStorage`, `IgniterStorageBuilder`, `IgniterStorageManager`, `IgniterStorageAdapter`, `IgniterS3StorageAdapter`, `IgniterS3Adapter`, `IgniterGoogleCloudStorageAdapter`, `IgniterGoogleAdapter`, `MockStorageAdapter`, and `IgniterStorageError`, plus public types for manager, builder, scopes, hooks, files, policies, replacement, and provider credentials. The `@igniter-js/storage/adapters` subpath exports the adapter classes and their credential/options types. The `@igniter-js/storage/telemetry` subpath exports `IgniterStorageTelemetryEvents`. Utilities (`IgniterStoragePath`, `IgniterStorageUrl`, `IgniterStorageMime`, `IgniterStorageEnv`, and `IgniterStorageTryCatch`) are exported from the package root.

<Callout type="info">
  `.build()` requires both a base URL (`.withUrl()` or `IGNITER_STORAGE_URL`) and an adapter (an adapter instance, `.withAdapter(key, credentials)`, or `IGNITER_STORAGE_ADAPTER`).
</Callout>
