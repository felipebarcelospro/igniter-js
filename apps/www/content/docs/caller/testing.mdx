---
title: Mocking & Testing
description: Define typed Caller mocks and exercise request code without sending real HTTP requests.
---

Caller supports mock registries that replace matching network requests. The mock builder uses schema paths for TypeScript checking; runtime response validation is configured on the Caller manager with `.withSchemas()`.

## Define a schema and mock registry

```ts
import { IgniterCaller, IgniterCallerMock, IgniterCallerSchema } from '@igniter-js/caller'
import { z } from 'zod'

const schemas = IgniterCallerSchema.create()
  .path('/users/:id', (path) => path.get({
    responses: {
      200: z.object({ id: z.string(), name: z.string() }),
      403: z.object({ message: z.string() }),
    },
  }))
  .build()

const mock = IgniterCallerMock.create()
  .withSchemas(schemas)
  .mock('/users/:id', {
    GET: {
      response: { id: '1', name: 'Mock User' },
      status: 200,
    },
  })
  .build()

const api = IgniterCaller.create()
  .withSchemas(schemas, { mode: 'strict' })
  .withMock({ enabled: true, mock })
  .build()
```

The mock registry's `.withSchemas()` method supplies compile-time path and response types. The Caller manager's separate `.withSchemas()` call enables runtime request/response schema validation.

## Test a request

```ts
import { describe, expect, it } from 'vitest'

describe('user API', () => {
  it('returns the mocked user', async () => {
    const result = await api.get('/users/:id')
      .params({ id: '1' })
      .execute()

    expect(result.ok).toBe(true)
    if (result.ok) expect(result.data).toEqual({ id: '1', name: 'Mock User' })
  })
})
```

## Mock an error response

```ts
const forbiddenMock = IgniterCallerMock.create()
  .withSchemas(schemas)
  .mock('/users/:id', {
    GET: { status: 403, response: { message: 'No access' } },
  })
  .build()

const forbiddenApi = IgniterCaller.create()
  .withSchemas(schemas, { mode: 'strict' })
  .withMock({ enabled: true, mock: forbiddenMock })
  .build()

const result = await forbiddenApi.get('/users/:id').params({ id: '1' }).execute()
if (!result.ok) console.error(result.error.message)
```
