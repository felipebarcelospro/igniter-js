## IgniterCaller

The main entrypoint for creating API client instances.

### `IgniterCaller.create()`

Creates a new `IgniterCallerBuilder` instance.

```typescript
const api = IgniterCaller.create()
  .withBaseUrl('https://api.example.com')
  .build();
```
