Caller provides a dedicated React client exposed via the `@igniter-js/caller/client` subpath. This ensures that the core library remains server-safe and avoids bundling React dependencies where they aren't needed.

## Setup

Wrap your application (or a specific part of it) with the `IgniterCallerProvider`.

```tsx title="providers/caller-provider.tsx"
import { IgniterCallerProvider } from '@igniter-js/caller/client'
import { api } from '@/lib/api'

export function CallerProvider({ children }: { children: React.ReactNode }) {
  return (
    <IgniterCallerProvider callers={{ main: api }}>
      {children}
    </IgniterCallerProvider>
  )
}
```

## Using the Hooks

The `useIgniterCaller` hook gives you access to your configured callers with full type safety and a TanStack Query-like interface.

```tsx
import { useIgniterCaller } from '@igniter-js/caller/client'
import type { api } from '@/lib/api'

// Define a typed hook for your app
export const useCaller = useIgniterCaller<{ main: typeof api }>()

function UserProfile() {
  const main = useCaller('main')
  
  const { data, isLoading, error } = main.get('/me').useQuery({
    staleTime: 10_000,
  })

  if (isLoading) return <div>Loading...</div>
  return <h1>Hello, {data?.name}</h1>
}
```

## Query Options

The `.useQuery()` method accepts several configuration options:

| Option | Description |
|--------|-------------|
| `enabled` | Set to `false` to disable the query from running automatically. |
| `staleTime` | Time in ms before the data is considered stale. |
| `params` | URL parameters for the request. |
| `headers` | Additional headers. |

## Mutations

For write operations, use the standard `.execute()` method inside an event handler or a `useEffect`.

```tsx
function CreateUser() {
  const main = useCaller('main')

  const handleSubmit = async (values: any) => {
    const { data, error } = await main.post('/users').body(values).execute()
    
    if (!error) {
      // Manually invalidate a query to trigger a refetch
      main.invalidate('/users')
    }
  }

  return <form onSubmit={...}>...</form>
}
```

<Callout type="info" title="Server Components">
  In Next.js App Router, you can use the standard `api.get().execute()` directly in Server Components. Use the React client only in Client Components.
</Callout>
