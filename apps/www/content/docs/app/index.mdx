`@igniter-js/app` is the React application shell for an Igniter client. It builds a route tree on [TanStack Router](https://tanstack.com/router), and lets route loaders and components use the same typed client, request context, and configured stores.

Use this package when you want your React routes to call a typed Igniter API and share application setup. The root entrypoint includes app and router builders, state, triggers, forms, navigation helpers, and an error boundary. Smaller state, trigger, and form imports are also available as subpaths.

## Capabilities

- Build an app with `.withClient()`, `.withContext()`, `.withStores()`, and optional trigger configuration.
- Define pages with typed search validation, loaders, metadata, and components.
- Build a TanStack Router tree and render it through `IgniterRouterProvider`.
- Add client-side state, UI triggers, and mutation-backed forms when needed.

<Callout type="info">
  This package is a React application layer. Create the API and its typed client with [@igniter-js/core](/docs/core) and connect the two through `IgniterApp.withClient()`.
</Callout>

## Package entrypoints

| Import | Use |
| --- | --- |
| `@igniter-js/app` | App and router builders, UI helpers, state, triggers, and `useForm` |
| `@igniter-js/app/state` | State builder and state-related exports |
| `@igniter-js/app/trigger` | Trigger builders and trigger-related exports |
| `@igniter-js/app/form` | `useForm` and its public types |

See the [API reference](/docs/app/api-reference) for the verified public exports. For the server API and client setup, start with [Core](/docs/core/quick-start); for API calls and client behavior, see [Caller](/docs/caller).
