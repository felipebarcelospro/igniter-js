`@igniter-js/app` connects an application client and context to pages and routes. It builds on [TanStack Router](https://tanstack.com/router) and adds typed page loaders, metadata, state, and triggers.

## Create an app and route

Pass your existing typed client to `IgniterApp`, define a page, then build the router and render it with `IgniterRouterProvider`.

```tsx title="src/app.igniter.tsx"
import {
  IgniterApp,
  IgniterRouter,
  IgniterRouterProvider,
} from '@igniter-js/app'
import { client } from './client'

const app = IgniterApp.create()
  .withClient(client)
  .withContext(() => ({ requestStartedAt: Date.now() }))
  .build()

const homePage = app.page('/')
  .withMetadata({ title: 'Home', description: 'Welcome to the app.' })
  .withComponent(() => (
    <main>
      <h1>Welcome</h1>
    </main>
  ))
  .build()

const router = IgniterRouter.create(app)
  .addRoute(homePage)
  .build()

export function App() {
  return <IgniterRouterProvider router={router} />
}
```

`withContext()` runs for route loads and makes its returned value available to loaders and triggers. The route tree is a TanStack Router instance, so TanStack Router's navigation and rendering model still applies.
